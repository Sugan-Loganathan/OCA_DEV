Website Sale - Hide Price & Cart(Public User)

This module provides configurable controls for restricting product pricing and cart visibility for public users.

Key Features

Based on company master configuration we can hide the price and cart in website for public user.

Step 1

Navigate to the Company Master.
The Website Configuration tab will be visible in the Company Master.

Step 2

For public user to hide the website price, enable the Hide Website Price field, and to hide the Add to Cart option, enable the Hide Cart field.

Step 3

After the above configuration if the public user visit the website means the price and cart details gets hided.

Step 4

After the above configuration, if a public user wants to know the product price, enter the contact number in the Call for Pricing Number field so they can reach you for pricing details.

Step 5

After adding the mobile number, it will be displayed on the website as shown in the screenshot below.
