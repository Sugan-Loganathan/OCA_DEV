# Delivery Acknowledgment

## Overview
The **Delivery Acknowledgment** module allows you to attach a signed proof of delivery document to delivery orders in Odoo. This helps maintain a record of customer confirmation for delivered products.

## Features
- Attach customer-signed acknowledgment documents to delivery orders
- Maintain proof of delivery for audit and verification
- Easy integration with existing stock picking workflow

## Usage
1. Go to **Inventory > Delivery Orders**
2. Open any delivery order
3. Upload the signed acknowledgment document in the attachment section
4. Save the record for future reference

## Description
Delivery acknowledgment signed by the customer at the time of product handover.  
Attached as confirmation of successful delivery.

## Technical Details
- Module Name: `delivery_acknowledge`
- Version: 19.0.1.0.0
- Depends: `base`, `stock`
